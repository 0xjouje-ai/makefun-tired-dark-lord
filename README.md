A 100-word monologue for Kevin, a fantasy dark lord who is secretly just very tired. Nine years into an eclipse scheme, he stands in a damp hall explaining the plan — again — to generals who nod and forget, and quietly slips away to count the stars on the stairs. The tiredness lives in the pauses, the trailing thoughts and the small deflections, never in a plain statement. The sting lands in the last line.

## Run it

```sh
node main.ts
```

It writes the monologue to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`).
